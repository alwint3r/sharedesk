Sharedesk — private Mac installer

Requirements
  Apple Silicon Mac running macOS 27 or newer.
  Tailscale access to your already-started Ubuntu X11 desktop.
  No Homebrew libraries are needed on the destination Mac.

Install
  1. Quit an existing Sharedesk viewer when convenient.
  2. Drag Sharedesk.app onto the Applications shortcut.
  3. Eject the disk image and open Sharedesk from Applications.

This private build has an ad-hoc signature, not an Apple Developer ID signature
or Apple notarization. If macOS blocks a copy you know and trust, try opening it,
then use System Settings > Privacy & Security > Open Anyway and confirm.
Do not disable Gatekeeper globally. This package is not a public release.

Connect
  Select a saved profile or enter the Ubuntu device's numeric Tailscale IPv4,
  VNC port and password, then click Connect. The host accepts one viewer at a
  time, so disconnect Screen Sharing or another viewer first.

Optional MCP access
  MCP is off each launch and listens only on this Mac at
  http://127.0.0.1:5917/mcp. Open Sharedesk > MCP Server, then Start Server.
  Copy Client Config and use your MCP client's OAuth sign-in action. Approve
  only a sign-in you initiated, after matching the browser and viewer codes.
  Client compatibility is limited to the implemented OAuth profile; the
  repository README documents the verified client setup.

  Authorized clients can read profile names and screenshots and may send them
  to an AI provider. Allow MCP Control permits mouse and keyboard input,
  including potentially destructive actions on Ubuntu. It starts off.
  Allow MCP Connection Management is a separate permission, also initially off.
  It permits saved-profile connections, exact-ID disconnects and retries after
  a connection ends. It survives VNC disconnects but resets on Stop or sign-in
  revocation. Connections need an already-approved saved Keychain password;
  MCP cannot request a password or open a Keychain approval dialog.
  MCP-created connections start with clipboard sharing and input control off.
  Stop or closing the MCP window ends access now, but remembered approvals
  can return on the next Start for up to 30 days. Require Sign-In Again
  revokes remembered access. Installing an update does not revoke it.

Existing data
  Installation does not include, replace or remove your saved profiles.
  They stay in ~/.sharedesk/profiles.json. Optional saved VNC passwords and
  remembered MCP authorizations stay in separate macOS Keychain items.
  macOS may ask for renewed Keychain access for this build.
  The app never connects automatically or saves a password in the profile file.

Update / remove
  Quit Sharedesk before replacing it with a new copy in Applications.
  To uninstall, quit it and move Sharedesk.app from Applications to the Trash.
  Profiles and Keychain items remain unless you remove them separately.
